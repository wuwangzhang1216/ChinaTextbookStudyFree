# #12：当前默认首课与人工验收交接

[PR #48](https://github.com/wuwangzhang1216/congcong-school/pull/48) 已合并，三个CI通过，[v1.7.3](https://github.com/wuwangzhang1216/congcong-school/releases/tag/v1.7.3) 已部署并通过线上复验，资源同步更新。本轮处理当前修订版路径遗漏的互动首课。首次开课直接呈现“从下面数，点亮第2层”的教学楼；选错可重试，选对进入练习，原文字讲解仍可打开。互动不计正式成绩、经验或掌握，不修改教材、题目ID、音频、判题或已完成成绩。

问题根因是原来的点数引导只绑定旧版 `g1up-u1-kp1`；当前默认的 `g1up-2026-u101-kp1` 仍进入三页文字讲解。新增与校园位置主题相符的互动，保留旧版点苹果。旧会话已经开始听讲解时继续原页；新互动选择、练习草稿及已判反馈沿用原保存机制。
