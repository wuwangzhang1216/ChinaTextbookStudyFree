## PR 深度评审的修复

针对 `77b2d19` 的5项发现已在本分支修复，证据见 [followup.json](ux-repair-evidence/followup.json)。新增概率题改为12格、9绿3黄，实际判分与独立算术断言一致，22段本地补充朗读均保留待教师听审状态。原模型签审作为历史记录保留，修订后的题目另记此次核验。

旧错题在进入复习时加载当前课程并更新相关快照，保留SRS盒子/日期/累计次数；移除确认已删除的题且不发奖励。加载异常或15秒停滞显示重试，显式新URL及no-store避免新/旧Service Worker沿用旧JSON。

续学新增完整内容标识（忽略音频地址）。内容一致可恢复草稿/反馈，不再次判分；内容改变或旧会话缺少内容标识时，未完成课程会一次性重开并说明原因，保留已经入账的奖励。此保守迁移会重置这一节未完成课的队列、计分和讲解进度，不能声称旧版所有局部进度都无损迁移。

新增 `review-content.ts`、`question-drafts.ts`、`content-math.ts` 回归；扩展 `lesson-resume.ts` 与Service Worker校验。课程更新与数据失败的浏览器证据使用本地受控响应，测试后已按原字节恢复产物；不代表真实线上更新或弱网/真机验收。
