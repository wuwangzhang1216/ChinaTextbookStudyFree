# v1.8.2：长数字答题与资源增量更新

本版包含 [PR #58](https://github.com/wuwangzhang1216/congcong-school/pull/58) 和 [PR #59](https://github.com/wuwangzhang1216/congcong-school/pull/59)，分别解决 #56 和 #57。

- 计算填空题移除 10 字符输入限制，屏幕与实体数字键盘均可完整输入长整数、负数、小数和分数，长答案可换行显示。
- 安装器先按目标版本清单核验本地文件，仅下载需要更新的分包。`--dry-run` 预览下载量，`--full-download` 强制全量更新，`--verify-only` 校验本地资源时无需下载归档。
- 教材、音频、图片及 iOS 逐册包与 v1.8.0 一致，继续引用原资源地址；只发布新版网页、匹配源码、清单和安装入口。保留 v1.8.1 的前台续学计时修复。

## 安装或升级

从 [v1.8.2 Release](https://github.com/wuwangzhang1216/congcong-school/releases/tag/v1.8.2) 下载本版 `install-release.py`，在原目录执行：

```sh
python3 install-release.py --tag v1.8.2 --mode static --root /path/to/existing-site --dry-run
python3 install-release.py --tag v1.8.2 --mode static --root /path/to/existing-site
```

Windows 将 `python3` 换成 `py -3`。源码部署省略 `--mode static`，备份代码修改后更新匹配源码并重新构建。完整命令、独立资源下载与覆盖目录见 [安装与升级说明](../release-install.md) 和 [下载导航](https://github.com/wuwangzhang1216/congcong-school/releases/download/v1.8.2/DOWNLOADS.md)。

增量更新按分包进行，包内任一文件变化仍需下载整个分包；首次安装需要完整资源。旧 Release 内的安装器不会自动更新，请先换用本版安装器。浏览器已有成绩保存在原协议、域名和端口下，升级不清除学习记录。
