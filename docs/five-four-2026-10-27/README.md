## 内容与本地验证

已接入26册、244个教学单元/活动，新增1,585个常规课时、10,974道题（含单元挑战）和375组英语听读。新教材使用独立的`54-qingdao`或`54-luke` ID；现有58册保留，教材选择区分五四制与六三制。

新增54,218段Edge语音全部完成MP3与AAC/M4A解码检查。页面实测发现并清理263处学生讲解文字，重新生成受影响语音；题目、答案、阅读原文和ID保持稳定。两处此前审校稿算术错误已更正，保留实际判题与替换音频回归验证。

本地检查包括完整构建、26册实际数据/判题/音频覆盖、独立算术筛查、旧教材数据与旧媒体逐字节比对、原生模拟器228项测试、84册原生资源包校验，以及浏览器中的选书、首次学习、准备活动和一年级至六年级切换。原有58册的116个原生ZIP逐字节复用。

长数学章节分知识点小组审校；早期审校记录中“缺少其他知识点”的说明针对当次小组，完整覆盖由目录映射及每知识点6题检查确认。模型编写、自动测试和原图复核不替代教师签审。
